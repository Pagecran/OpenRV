x264 / H.264 Encoding Support (Optional)

Open RV can optionally be built with x264 support for H.264 / MP4 export.<br>
x264 is licensed under GPL v2 or later and is also available under a commercial license.<br>
In this fork, combining x264 with the bundled OpenSSL 3 build requires FFmpeg to be built with `--enable-gpl --enable-version3`, which changes the redistribution obligations of the resulting binaries.
